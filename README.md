## How to check the dates

1. **The files.** Compute each file's SHA-256, with `shasum -a 256 <file>` on a Mac or `sha256sum <file>` elsewhere, and compare it with the list above.
2. **The time stamps.** Each PDF carries an RFC 3161 time stamp from freetsa.org, an independent time-stamp authority. It vouches that the PDF's exact bytes existed at the time shown. Adobe Acrobat Reader shows each time stamp in its Signatures panel. freetsa.org publishes the SHA-256 of its two certificates, cacert.pem `2151b61137ffa86bf664691ba67e7da0b19f98c758e3d228d5d8ebf27e044438` and tsa.crt `8bfb0305bb64e2571ca507552ef3245cb1c2fee8728e0ff8689225081ea13467`, and the certificates inside these time stamps match them.
3. **The uploads.** GitHub signed each upload commit, and marks it Verified in the repository's history.
